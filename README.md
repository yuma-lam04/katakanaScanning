# カタカナ視認スクリーニング

カタカナ単語を短時間フラッシュ表示し、見えた単語を入力してもらうことで、
読み取り(視認)の傾向を簡易的にチェックするWebアプリケーションです。
医療的な診断ツールではありません。

## 機能

- **フラッシュ提示**: 注視点(1秒) → 単語表示(200/500/1000ms) → マスク → 入力、の流れで出題
- **条件設定**: 語彙レベル(日常/ビジネス/学術/IT)、単語長、フォント、文字サイズ、字間、コントラスト、提示時間
- **入力モード**: IMEでの直接入力、またはローマ字入力(リアルタイムでカタカナ変換プレビュー)
- **練習モード**: 固定5問で操作に慣れてから本番へ
- **結果表示**: 正答率、平均反応時間、全試行の正誤・未認識一覧
- **履歴保存**: ブラウザ内(localStorage)への保存、履歴確認、CSVエクスポート、削除
- **再現性**: Seed値を指定すると同じ問題セットを再現可能(自動生成されたSeedも結果に記録)

## 技術スタック

- React + TypeScript
- Vite
- seedrandom (乱数制御)
- wanakana (ローマ字→カタカナ変換)
- Vitest (テスト)

## セットアップ手順

### 前提
- Node.js (v18以上推奨) がインストールされていること

### インストール

```bash
npm install
```

### ローカル実行 (開発モード)

```bash
npm run dev
```
ブラウザで `http://localhost:5173` を開いてください。

### ビルド

```bash
npm run build
```
`dist` フォルダに静的ファイルが生成されます。任意の静的ホスティングに配置できます。

### テスト

```bash
npm test
```

## 自動テストの範囲

- 変換・出題生成・辞書・保存の単体テストに加え、出題画面の表示順、IME変換中の Enter、本番・練習・中断時の主要な画面遷移を jsdom 上で検証します。
- 実端末の IME 挙動、実際の描画時間、フォントの有無による表示差、および画面を隠した場合のブラウザ固有の挙動は自動テストの対象外です。

## 表示確認（2026-09-20）

- Chromium のモバイル相当幅 320px・375px で、文字サイズ 40px、字間 0.1em、長い単語の条件を確認しました。長い単語は表示パネル内に収まり、折り返し・欠け・ページ全体の横スクロールは再現しませんでした。
- ローマ字プレビューと回答欄、結果一覧で使う `results-table` も横幅内に収まりました。そのため、指定した文字サイズを変更する修正は行っていません。

## ロジック解説

### 1. 刺激生成 (`src/core/generator.ts`)
- 語彙レベルと単語長でフィルタした単語プールから、Seed付き乱数でシャッフルして出題します。
- 条件に合う単語が不足する場合は、単語長 → 語彙レベルの順に制約を緩和します。
- 同一セッション内で同じ単語は出題されません。

### 2. ローマ字変換 (`src/core/converter.ts`)
- wanakana をベースに、長音記号(`-` → `ー`)や `nn` の扱いを独自に正規化しています。

### 3. 採点と計測 (`src/views/TestRunner.tsx`)
- 反応時間 (RT) は、刺激提示開始からボタン押下までの時間を `performance.now()` で計測します。
  タイピング時間を含むため、「回答完了までの時間」として解釈してください。
- 判定は入力文字列と正解の完全一致です。
- 「見えなかった」を選んだ試行は不正解として正答率に含め、選択するまでの時間を平均反応時間に含めます。
- テスト中にタブ移動やウィンドウ最小化で画面が非表示になった場合、その問題は記録せず中断します。復帰後は、同じ問題を最初から提示してやり直します。

## 注意事項

- 本ツールはリフレッシュレートや入力遅延の厳密な制御(医療用機器レベル)は行っていません。相対的な傾向を見る用途としてお使いください。
- 外部サーバーへのデータ送信は一切行いません。データはすべてブラウザ内に保存されます。
- フォント設定は希望するフォント名です。端末にないフォントは代替フォントで表示され、CSVの `Config_Font` には実際の表示フォントではなく指定したフォント名が記録されます。

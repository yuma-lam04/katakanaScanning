# カタカナ形取り違えスクリーニング (Katakana Soramime Screening)

読み間違い（空目）の傾向をチェックするための簡易PWAアプリケーションです。
医療的な診断ツールではありません。

## 機能

- **単文字判別**: 紛らわしいペア（シ/ツ, ソ/ン等）の識別テスト
- **擬似単語判別**: 文脈（擬似単語）の中での識別テスト
- **コントロール課題**: 紛らわしくない文字でのベースライン確認
- **条件設定**: フォント、サイズ、字間、コントラスト、提示時間の変更
- **結果分析**: 正答率、反応時間、ペアごとの混同傾向の可視化
- **履歴保存**: ブラウザ内（localStorage）への保存とCSVエクスポート

## 技術スタック

- React + TypeScript
- Vite
- Chart.js (結果グラフ描画)
- seedrandom (乱数制御)
- vite-plugin-pwa (PWA化)

## セットアップ手順

### 前提
- Node.js (v18以上推奨) がインストールされていること

### インストール

```bash
npm install
```

### ローカル実行 (開発モード)

```bash
npm run dev
```
ブラウザで `http://localhost:5173` を開いてください。

### ビルド

本番用にビルドする場合:

```bash
npm run build
```
`dist` フォルダに静的ファイルが生成されます。

## PWAとしてインストール

1. サーバー上（またはローカルホスト）でアプリを開く
2. ブラウザのアドレスバーにある「インストール」アイコンをクリック、またはメニューから「ホーム画面に追加」を選択
3. オフラインでも起動可能になります

## ロジック解説

### 1. 刺激生成 (`src/core/generator.ts`)
- `seedrandom` を使用し、Seed値が同じなら常に同じ問題順序を生成します。
- **単文字課題**: ターゲットとディストラクター（誤り選択肢）を提示。
- **擬似単語課題**: ランダムなカタカナ列の中にターゲットを混入させます。
  - 例: ターゲット「シ」, ベース「レ○トム」 -> 「レシトム」
  - 選択肢は「シ」と「ツ」のボタンになります。

### 2. 採点と集計 (`src/views/TestRunner.tsx`, `src/views/Results.tsx`)
- 反応時間 (RT) は、刺激提示開始(displayStartTime)からボタン押下までの時間を `performance.now()` で計測します。
- **混同行列**: どのターゲット(正解)に対して何を答えたかを記録し、特定のペアのみ誤りが多いかを集計します。
- **コントロール課題**: 明らかに形の違うペア（カ/タなど）の正答率が低い場合、視覚的な識別力以前に、注意・疲労・操作ミスの可能性を示唆します。

## 注意事項

- 本ツールはリフレッシュレートや入力遅延の厳密な制御（医療用機器レベル）は行っていません。相対的な傾向を見る用途としてお使いください。
- 外部サーバーへのデータ送信は一切行いません。データはすべてブラウザ内に保存されます。

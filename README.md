# カタカナ視認スクリーニング

カタカナ単語を短時間表示し、見えた単語を入力して、読み取りの傾向を簡易的に確かめる Web アプリです。医療的な診断を行うものではありません。

## できること

- 単語を短時間表示し、直接入力またはローマ字入力で回答できます。
- 問題数、単語の難しさ・長さ、提示時間を選べます。
- フォント、文字サイズ、字間、コントラストなどの細かな条件は「高度な設定」から変更できます。
- 正答率と平均反応時間を確認でき、履歴の確認・CSV 出力・削除もできます。

## 使い方

1. 注意事項を読み、「同意して開始する」を押します。
2. 測定条件を選び、必要なら「高度な設定」を開きます。
3. 「テスト開始」を押して回答します。まず操作を試したい場合は「練習」を選べます。
4. 結果を確認します。保存済みの履歴は設定画面からいつでも確認できます。

## データと注意事項

- 結果はこのブラウザ内にだけ保存され、外部サーバーには送信しません。
- 保存済みの履歴は設定画面から CSV に出力したり削除したりできます。
- 本ツールは診断や厳密な視機能測定には使えません。日常生活で困りごとが大きい場合は、眼科医や専門家に相談してください。

## 開発時の起動

```bash
npm install
npm run dev
```
